# ADR-002 · 买断制为主，不做订阅

> **状态**：已决策（PRD v2.0）
> **决策日期**：2026-09-26

## 背景

PRD §10 写了三种商业形态：免费版 / Pro 买断 / 官方中转。决策点是 Pro 走**买断**还是**订阅**。

## 决策

**Pro ¥98–168 买断**（一次性），不开订阅。

## 论据

### 选买断的理由

1. **与 BYOK 模型自洽**：用户已经在付 token 费（按用量），我们再加订阅会让总账不可预测；买断是一次性透明
2. **官网对比表利器**：Typeless $144/年 vs 译语 ¥168 买断——一年回本，可以写进官网头图
3. **目标用户特征**：BYOK 用户偏开发者/技术型，更接受一次性付费 + GitHub Sponsors 模式
4. **避免订阅疲劳**：被订阅收割过的用户抵触订阅

### 定价区间说明

- ¥98：保守起步价，覆盖"基础 Pro"配置
- ¥168：建议价，覆盖完整 Pro（含 Skill 市场）
- 区间给上市留弹性

### 免费版策略

- 周用量上限建议 **10,000 字**（高于 Typeless 的 8,000）—— 留出足够日常使用
- 2 个模型配置 + 本地 Whisper——基础体验完整
- 不放 OCR / Skill 市场 / 隐私锁 / 术语表

### 官方中转（可选）

按量计费，**默认关闭**。给不愿绑卡、不愿折腾 Key 的用户兜底。不主动推，避免和 BYOK 价值主张冲突。

## 后果

- 没有持续现金流——这是工具型软件的常见取舍
- 收入靠"卖工具 + 卖服务"，靠口碑 + 一次性付费
- 需考虑长期维护资金：Skill 市场可以带来持续内容供给（用户共建）

## 关联

- PRD §10 商业模式
- 与 ADR-001 协同：BYOK + 买断 = "工具型 AI 软件"的标准范式
