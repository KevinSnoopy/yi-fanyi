# 竞品分析 · Bob

> 来源：Kimi PRD 提到（PRD v2.0 §1.1）
> 状态：待调研

## 基本信息

| 项 | 值 |
|---|---|
| **形态** | 划词翻译 / 截图翻译（macOS only） |
| **底层** | 多种翻译服务（含 Google/DeepL/ChatGPT） |
| **价格** | 买断 ¥50 |

## 与译语流程重叠

- 流程 C：划词翻译（⌥D / Ctrl+Alt+D）
- 流程 E：截图 OCR 翻译（⌥S / Ctrl+Alt+S）
- 流程 D：静默替换翻译（⌥回车）

PRD 直接借鉴了 Bob 的热键设计 + 静默划词逻辑 + 异常规则（焦点变化终止 + toast）。

## Bob 的已知 UX 细节

- **异常规则**：静默替换进行中若焦点变化，立即终止 + toast
- **热键**：⌥D 划词、⌥S 截图（与 PRD 一致）
- **OCR 是 P1**（译语对齐）—— Bob 这块做得早但不一定好

## 译语相对优势

- **全平台**：Bob 仅 macOS，译语五端
- **BYOK**：Bob 部分插件支持但不是主流程
- **语音**：Bob 完全没做语音
- **隐私**：Bob 本地化做得不错（译语同等水平）
