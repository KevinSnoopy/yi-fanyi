# 竞品分析 · Chatterfly

> 来源：Kimi PRD 提到（PRD v2.0 §1.1）
> 状态：待调研

## 基本信息

| 项 | 值 |
|---|---|
| **形态** | 语音输入 → 混元润色 → 写回输入框 |
| **平台** | macOS / Windows（移动端未发布） |
| **底层** | 混元（Tencent Hunyuan） |
| **价格** | 免费 |

## 与 Typeless 的关键差异

- 用混元而不是自研/LLM 兼容
- 至今没出移动端（移动输入法格局已定）
- 免费策略

## 译语相对优势

- BYOK（Chatterfly 锁定混元）
- 覆盖 Linux + 移动端
- 离线可用
- 翻译能力（Chatterfly 主要做语音成稿，没有专门的翻译流程）
