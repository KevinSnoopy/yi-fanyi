## 核心能力（内测报道汇总）

1. **开口即成稿**：区别于传统语音转文字——理解上下文语义，自动剔除口语冗余、梳理逻辑，直接输出通顺书面文稿
2. **六大自然场景 Skill**（内置）：
   - 会议纪要
   - 工作汇报
   - 项目进度梳理
   - 营销文案
   - 邮件润色
   - Vibe-Coding 提示词优化（口述需求 → 优化为提示词）
3. **全局唤起**：微信、QQ、文档编辑器等各类应用内直接调用，不用切换窗口
4. **复杂环境适配**：嘈杂、弱网、轻声低语等录音环境
5. **个人化**：逐步学习用户表达习惯、优化输出风格；支持个人词库维护

## 与 Typeless 的关键差异

| 维度 | Chatterfly | Typeless |
|---|---|---|
| 模型 | 锁定混元（不可换） | 自家云端（不可换） |
| 场景化 Skill | **六场景内置（核心卖点）** | per-app 语气自适应（无显式 Skill 模板） |
| 翻译 | **无专门翻译流程** | 100+ 语言边说边译（第 2 feature） |
| 价格 | 免费 | Free 8k 词/周 + Pro $12–30/月 |
| 移动端 | 未发布 | iOS/Android 原生已上线（2025-12 起） |
| 数据 | 录音/转写默认本机 | 宣称 zero cloud retention |

## 译语相对优势（对位更新后）

- **BYOK**（Chatterfly 锁定混元）+ **翻译能力**（Chatterfly 没有专门翻译流程）仍是双护城河
- 覆盖 Linux + 移动端（Chatterfly 移动端未出）
- 离线可用（Ollama / 本地 Whisper）
- **警示**：Chatterfly 的「六场景 Skill + 本地存储 + 免费」组合对国内用户吸引力极强，且有大厂渠道（微信/QQ 生态）加持

## 对译语的具体启示（2026-09 版）

1. **六场景 Skill 应直接对齐**：会议纪要/工作汇报/项目进度/营销文案/邮件润色/Vibe-Coding——v6 原型 Tab K 仅 3 张卡（会议纪要/商务邮件/营销文案），应补齐为 6 张（v7 落地）
2. **「成稿为主、翻译为开关」范式被 Chatterfly 再次验证**（它压根没有翻译，仍是「表达助手」定位）——流程 A 默认行为应为同语言成稿润色
3. **本地存储是两家共同姿态**：译语「零采集 + BYOK + 离线」定位与赛道一致且更彻底，无需调整
4. **免费大厂竞品压境**：买断制定价（ADR-002）需要更强的差异化叙事（BYOK + 全平台 + 翻译 + 离线）

## 风险信号

- 「商业对手免费补贴」是 PRD v2.0 §11 列的风险之一——Chatterfly + 微信输入法是典型代表，**2026-09 内测意味着该风险已实质化**
- 应对：不拼模型质量、不拼免费，拼 **BYOK + 隐私彻底性 + 全平台 + 翻译**
