## 关键决策与理由

- **用 HTML 而非 Flutter widget 写原型**：HTML 在浏览器里 0 配置可看，录屏/截图/分享最便利；Flutter widget 需要 `flutter run` 跑 macOS app，工程脚手架级动作，未授权前不冒进
- **覆盖 PRD §6 #1（录音条三态）+ #2（悬浮窗四态）**：next_steps 选项 ① 描述的两个组件，三态与四态是高频组件，先做出来验证设计语言
- **加状态切换控件 + 浅深主题切换**：让评审方可以一站式切换所有状态与主题，比每次部署新链接快

## 关键设计约束（来自 PRD §5）

- 录音 / 状态条 280×32px，底部居中偏上 80px
- 悬浮窗 380×自适应（min 120/max 480），圆角 14px，阴影 y8 blur24 24%黑
- 品牌主色 #4F7CFF / #5B8CFF（深），强调色 #FF7A45 / #FF8A5C（深）
- 字体 PingFang SC / Inter，译文 15px
- 悬浮窗半透明：浅 #FFFFFFEB（92%） / 深 #1E1F24E0（88%）
- 动画 ≤ 180ms
