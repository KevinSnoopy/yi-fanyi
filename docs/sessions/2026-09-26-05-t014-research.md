## 关键发现（不读完整 README 也必须知道）

### 1. 翻译不是这一类产品的核心叙事

| 产品 | slogan | 翻译位置 |
|---|---|---|
| Typeless | Speak, don't type | 2nd feature (Dictate → Translate → Ask) |
| Wispr Flow | Don't type, just speak | 末尾 feature |
| Spokenly | Think out loud | 100+ 语言里提一句 |
| MacWhisper | friendly redesign | 支持但定位是任意音频转录 |

**没有任何一家把翻译当主卖点**。

### 2. 跨 App 工作 + 隐私 = 核心差异化锚

- Typeless 展示 154 个 app logo（"Works everywhere"）
- Wispr Flow "every device" + "Built around how you work"
- Spokenly "in any app"
- 4 家都强调本地处理 / BYOK 隐私

### 3. 视觉范式高度一致

- 100% 深色模式
- 大圆角 12-20px
- 录音按钮 = 圆形 + 波形动画 / pill-shape 悬浮条
- 主色以蓝色系为主（Wispr #4D65FF，Spokenly 亮蓝，MacWhisper 蓝）
- 字体 Inter / SF Pro

### 4. 录音条形态有三种范式

- **Typeless pill**：黑色胶囊形 128-160×36，内部白色波形
- **Wispr Flow bar**：iOS 键盘顶部 32-44px 横条
- **Spokenly 悬浮窗**：macOS 中下方 280×80 卡片，红色录音点

**译语建议**：A 为主（屏幕中央 pill）+ C 为辅（macOS 长录音时）

### 5. 翻译功能的产品化路径（启发）

- Typeless："Translate as you speak"（100+ 语言，边说边译）—— **作为开关**，默认关闭
- Spokenly：模型选择器 + 语言选择器，**设置项而不是常驻 UI**
- 译语应借鉴：录音条右侧小开关，开启后悬浮窗显示双语

## 关键决策与理由

- **跳过单独的 4 个详细 .md 页**：所有发现已在 README 里完整覆盖，再开 4 个文件会增加目录噪音；如需细分，从 README 拆即可
- **Vision 工具 1 张/次而非 9 张/次**：第一次 9 张调用 timeout（已知问题），第二次 2 张也 timeout，第三次 1 张成功——经验是 vision 工具单次 size 必须 ≤ 1 张
- **不画截图到原文**：截图作为独立文件保留在 `screenshots/` 子目录，正文用文字描述引用，避免 README 体积爆炸
- **未做实际浏览器渲染**：环境缺 nspr/nss 系统库无法启动 chromium；用 HTML 解析 + 图片理解组合达成 80% 等价效果
