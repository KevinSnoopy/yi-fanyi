# Prototypes · 设计原型

> **⚠️ v1 已作废（2026-09-26）**
> 用户反馈：「你借鉴的是有道翻译，他是上个世纪的产品」「该产品的目的应该是通过语音输入在任何输入框内输入文字，包括翻译等」。
> 本目录 v1（录音条三态 + 悬浮窗四态）错误地把"翻译"做成了产品主角；
> 正确范式是「语音输入为主、翻译可选」，参考系应是 Typeless / Wispr Flow / Chatterfly，
> 不是有道翻译。
> 调研结论与新版原型见 `docs/competitor-research/`（待写）。
> 线上预览链接 **https://kox5otr2as3d.space.mcode.cn** 仅作历史记录，请勿评审。

## 使用

直接用浏览器打开 `index.html`，左上角浮动控件可切换主题与状态。

线上预览：**https://kox5otr2as3d.space.mcode.cn**（演示页 → 录音条单页 → 悬浮窗单页，**v1 作废，仅留档**）

## 不做什么

- 不接入真实 STT / LLM / 流式协议（mock 数据足够验证设计语言）
- 不引入第三方 UI 库（Tailwind / Element Plus 等）；保持零依赖，方便迁移到 Flutter
- 不打包、不构建；纯文件，git diff 即变更
