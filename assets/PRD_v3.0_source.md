## 1. 产品概述

### 1.1 一句话定位
按住说话（或打一句话），译文自动落进你正在输入的地方——用你自己的模型 Key，离线也能用。

### 1.2 三大支柱
1. **BYOK**：任意模型平台 Key 自由配置（OpenAI 兼容 / Anthropic / Gemini / 自定义 BaseURL）
2. **全平台 + 离线**：macOS / Windows / Linux / iOS / Android 五平台覆盖；支持 Ollama 本地模型、Whisper 本地转写
3. **隐私优先**：数据不出本机，流量直连模型方，零遥测

### 1.3 目标用户
- 跨语言办公/学习者
- 出海从业者、跨境电商客服
- 多语开发者、隐私敏感人群
- iOS/Android 移动端跨语沟通

### 1.4 竞争对位

| 维度 | Typeless | Chatterfly | Bob | **译语** |
|---|---|---|---|---|
| 核心形态 | 语音键盘→润色成稿 | 语音输入→混元润色 | 划词/截图翻译 | **语音+文本翻译输入** |
| 平台 | macOS/Win/iOS/Android | macOS/Win | 仅 macOS | **五平台全覆盖** |
| BYOK | ❌ | ❌ | 部分插件 | ✅ **任意平台** |
| 离线/本地模型 | ❌ 纯云端 | ❌ | ❌ | ✅ **Ollama/端侧** |
| 隐私 | 采集周边文本 | 录音本地 | 本地 | **零采集、全本地** |
| 价格 | $12–30/月订阅 | 免费 | 买断 ¥50 | **买断制 + 免费版** |

## 2. 核心使用流程 (六大流程)

### 流程 A：按住说话 → 译文落框 (P0，核心体验)
**场景**：用户在 WhatsApp/Telegram/邮件里给外国客户发消息

```
① 光标在任意输入框
② 按住 Fn（默认，可改）→ 屏幕底部浮出细录音条（波形动画 + 计时）
   说中文："那个报价我确认没问题，下周三之前可以签合同"
③ 松开 Fn → 录音条变"转写/翻译中"状态条（显示已输出字符数）
   - 语音转写（本地 Whisper 或用户配置的 STT API）
   - 自动去口头禅、补标点、按语境成稿
   - 翻译成目标语言，流式输出
④ 状态条预览译文 1.2 秒（可点展开编辑）→ 自动写入输入框并消失
   Esc 随时取消
```

**关键规则**：
- 按住说话、松手成稿：过程中用户不离开当前应用，无悬浮窗打断
- 预览期 1.2 秒 = "后悔窗口"；设置可改"直接写入"或"总是预览"
- 长语音无 6 分钟硬上限（吸收 Typeless 痛点）
- 中途说错 → 继续说"不对，改成……" — 成稿引擎只保留最终意图

### 流程 B：悬浮窗输入翻译 (P0)
`⌥+空格 / Alt+空格` → 鼠标旁弹出迷你悬浮窗 → 直接打字/粘贴（自动读剪贴板）→ 流式显示译文 → Enter 写回并关闭；`⌘/Ctrl+Enter` 仅复制

### 流程 C：划词翻译 (P0)
选中任意应用文本 → `⌥+D / Ctrl+Alt+D` → 选区旁浮出译文小窗 → 点空白关闭 / 点"替换"写回 / 点喇叭朗读

### 流程 D：静默替换翻译 (P0，无窗口打断)
输入框敲好中文 → `⌥+回车 / Ctrl+Alt+回车` → 底部状态条显示进度（翻译中…已输出 N 字，可取消）→ 完成：原文被译文替换；期间切换焦点则终止并 toast

### 流程 E：截图 OCR 翻译 (P1)
`⌥+S / Ctrl+Alt+S` → 框选区域 → 悬浮窗双栏「原文 | 译文」，均可复制

### 流程 F：移动端键盘 (P1)
**键盘模式**：唤出「译语键盘」→ 顶部 36px 工具条（语言方向中→英可互换 / 翻译开关 / 🎤 / 大切换键）→ 打字中文 → 候选区流式出英文译文 → 点上屏

**iOS 已知限制与对策**（吸收 Typeless 差评第一痛）：
- 系统不允许自动切换键盘 → App 内提供"引导开启键盘 + 添加到常用列表"教程；键盘上放显眼大切换键
- 键盘内不能访问麦克风 → 语音翻译走"App 内录音 → 译语文本 → 分享/复制"流程；键盘内只做文本翻译
- 不占用 emoji 键位，译语键放工具条左侧

## 4. 交互与热键设计

参照系：ChatGPT 桌面版（修饰键+空格唤起）、Bob/有道（Ctrl/⌥+Alt+字母翻译动作）、Typeless/Chatterfly（Fn 按住说话）。

| 功能 | macOS | Windows / Linux | 参照 |
|---|---|---|---|
| 语音输入（按住说话） | 按住 Fn | 按住 Fn | Typeless / Chatterfly |
| 唤起悬浮窗 | ⌥ + 空格 | Alt + 空格 | ChatGPT 桌面版 |
| 划词翻译 | ⌥ + D | Ctrl + Alt + D | Bob / 有道 |
| 截图翻译 | ⌥ + S | Ctrl + Alt + S | Bob / 有道 |
| 静默替换翻译 | ⌥ + ↩ | Ctrl + Alt + ↩ | Bob 静默划词 |
| 打开主窗口 | 双击 ⌥ | 双击 Ctrl | 有道 |
| 临时禁用全部热键（演示/摸鱼模式） | ⌥ + ⇧ + P | Ctrl + Alt + P | 自研 |

**交互规则**：
1. 全部可重绑，实时冲突检测（含微信截图 Ctrl+Alt+A 等常见占用提示）
2. 唤起键单次触发、语音键按住触发，两类手感必须区分
3. 静默替换进行中若焦点变化，立即终止并 toast
4. 悬浮窗动画 ≤ 180ms（淡入 + 上移 8px），不抢焦点
5. 热键全局生效：macOS 需引导开启"辅助功能 + 输入监控"权限，首次启动走授权引导流程

## 5. 设计风格规范

### 5.1 基调
轻盈、无侵入、半透明质感——"伴随型"软件的存在感必须低于宿主应用。
参考系：Chatterfly（浅色圆角卡片 + 柔和蓝紫渐变）、Bob（紧凑悬浮窗）、Typeless（极简录音条）。

**圆角**：悬浮窗 14px / 卡片 10px / 按钮 8px / 输入框 10px
**阴影**：悬浮窗 24% 黑投影 (y8, blur24)
**尺寸**：
- 迷你悬浮窗 380 × 自适应 (min 120 / max 480px 滚动)
- 划词小窗 320 × 自适应
- 录音/状态条 280 × 32px，屏幕底部居中偏上 80px (Typeless 式细条)
- 主窗口 960 × 640 (最小 720 × 480)

### 5.2 Design Tokens

| Token | 浅色 | 深色 |
|---|---|---|
| 品牌主色 | #4F7CFF | #5B8CFF |
| 强调色 (CTA/发送) | #FF7A45 | #FF8A5C |
| 悬浮窗背景 | #FFFFFFEB (92%) | #1E1F24E0 (88%) |
| 正文 / 次要文字 | #1D2129 / #86909C | #E8EAED / #9AA0A6 |
| 分割线 / 原文区底 | #F0F1F5 / #F7F8FA | #2E3038 / #26282F |
| 错误态 | #F53F3F | #F76965 |
| 字体 | PingFang SC / HarmonyOS Sans + Inter；译文区 15px | 同左 |

### 5.3 核心组件规格

**① 录音/状态条 (最高频组件)**
```
[◉●●● 波形]  00:07             ← 按住说话态：主色波形动画 + 计时
[✕] 翻译中… 已输出 32 字  →     ← 处理态：可点展开、可取消、显示字数
[✓] "Confirmed, we can sign…"   ← 预览态 1.2s 后自动写入
```

**② 迷你悬浮窗**
```
┌──────────────────────────────────────────┐
│ [🌐 中 → 英 ▾]              [🔊] [⚙] [✕] │
│┌────────────────────────────────────────┐│
││ 原文（浅灰底，可折叠）                  ││
│└────────────────────────────────────────┘│
│┌────────────────────────────────────────┐│
││ 译文流式输出区（白底，顶部 2px 进度条）  ││
│└────────────────────────────────────────┘│
│ [🎤] [输入消息…                    ] [➤发送]│
└──────────────────────────────────────────┘
```

**③ 划词小窗**：原文 12px 次要色在上、译文 15px 在下，底部图标排 (复制/替换/朗读/收藏/进主窗)

**④ 设置页 (主窗内，左侧导航)**：模型配置 / 快捷键 / 翻译偏好 / 术语表 / Skills / 历史与用量 / 隐私安全
- **模型配置为灵魂页面**：平台卡片网格 (OpenAI / Anthropic / Gemini / DeepSeek / 通义 / 火山 / Ollama / 自定义 OpenAI 兼容) → BaseURL + Key + 模型下拉 (支持拉取列表) + 测试连接

**⑤ 移动端键盘**：与系统键盘同高；顶部 36px 工具条；候选区为"译文流"

**⑥ 首次引导三步**：选平台 → 填 Key (附各平台申请链接，支持"先用本地模型试用"零门槛体验) → 设热键。无强制登录。

## 7. 异常与边界

| 场景 | 处理 |
|---|---|
| Key 无效 / 欠费 / 限流 | 内联错误条显示模型方返回 + 直达配置页 |
| 断网 | 提示切换"离线模式" (本地 Whisper + 本地 LLM 若已配置) |
| 静默替换中焦点切换 | 终止任务，toast 提示，原文不动 |
| 未配置任何模型 | 默认引导"本地模型一键体验"，绝不白屏 |
| 隐私锁开启 | 主窗需 FaceID/密码；悬浮窗功能不受影响 |
| 热键被占用 | 设置页红字提示占用方 |
| iOS 键盘未启用 | App 检测后弹引导，一键跳系统设置 |

## 8. 非功能需求

- **性能**：热键到窗口可见 < 150ms；首 token < 1.5s (主流 API)；录音条 60fps 波形
- **隐私**：零遥测默认；请求只发往用户配置的 BaseURL；不采集宿主应用任何上下文文本 (对标 Typeless 争议点，写入隐私政策)
- **稳定性**：热键监听崩溃自愈；更新不丢配置
- **国际化**：界面中/英双语
- **可访问性**：键盘可达性、VoiceOver 朗读、对比度 AA

## 9. 技术架构 (概要)

**Flutter (UI+业务) + 原生桥 (热键/剪贴板/焦点/IME/麦克风/钥匙串) + Provider 适配层 (OpenAI 兼容 / Anthropic / Gemini / 自定义 / Ollama 本地) + SQLite + 系统密钥存储**

## 12. 架构决策记录 (ADR)

### ADR-001：macOS 菜单栏范式 vs 独立窗口 (2026-09-26 决策)
**决策**：采用 macOS 原生范式——菜单栏常驻 + 浮窗 (Popover)，不是独立窗口 App。
**理由**：符合"伴随型"产品定位 (存在感低于宿主应用)；菜单栏占用最小空间；Popover 模式更轻量。
**影响**：主窗口在 macOS 上是次要入口，主要交互通过菜单栏图标 + Popover 完成。

### ADR-002：原型 SPA App 化 vs 多页路由 (2026-09-26 决策)
**决策**：单 index.html + app.js + _shared.css (3 文件，无路由目录)，内部用 ⌘1-6 切换视图。
**理由**：原型阶段避免框架负担；所有交互在一个 HTML 里；更易部署和验收。
**影响**：v5 起所有视图统一到 SPA，URL hash 切换视图。

### ADR-003：Provider 接口设计原则 (2026-09-26 待定)
**决策**：所有模型方 (OpenAI / Anthropic / Gemini / Ollama / 自定义) 实现统一 `TranslationProvider` 接口。
**接口草案**：
```dart
abstract class TranslationProvider {
  String get name;
  String get defaultBaseUrl;
  Stream<String> translate({
    required String text,
    required String sourceLang,
    required String targetLang,
    String? systemPrompt,
    String? glossaryJson,
  });
  Future<bool> testConnection();
  Future<List<String>> listModels();
}
```
**待定项**：错误模型 (ErrorCode 枚举)、重试策略、流中断恢复。

### ADR-004：录音条三态必须 first_frame 锚定 (2026-09-26 沉淀)
**决策**：录音条说话/处理/预览三态的原型图必须三态并列展示，不能只画静态单态。
**理由**：三态切换是核心交互，单态会让验收者无法评估状态流转。
**影响**：v6 原型 Tab A 明确分三栏展示。

## 13. 原型验收清单 (Definition of Done)

用户验收时按此清单过：
